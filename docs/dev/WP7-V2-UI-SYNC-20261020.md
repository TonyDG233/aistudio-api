## 3. P2 账号管理

### 3.1 结构

账号平铺，不再使用 Cookie 组 → 子账号层级。来源文件只作为小字。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 账号管理                                      [导入账号] [刷新]             │
│ 一条账号一行；实例有编号；实例是并发登录容量。                               │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ u/0  tonygemini38@gmail.com   [pro]                  来源：auth-5.json      │
│                                                                              │
│ ┌ 实例 #1  [当前实例] ────────────────────────────────────────────────────┐ │
│ │ 服务渠道：PG + Build      在途请求：1                                  │ │
│ │ [切换到此实例]   [关闭实例]                                            │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│                                                                              │
│ [+ 新建实例]                                                                 │
│                                                                              │
│ u/0  odindicola5@gmail.com   [free]                  来源：auth-1.json      │
│                                                                              │
│ ┌ 实例 #2 ────────────────────────────────────────────────────────────────┐ │
│ │ 服务渠道：PG              在途请求：0                                  │ │
│ │ [切换到此实例]   [关闭实例]                                            │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│                                                                              │
│ [未登录]  [新建实例]                                                         │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 账号状态

- 有实例：显示实例卡；
- 无实例：`未登录` + `新建实例`；
- 账号失效：`账号失效` + `重新登录`，不允许新建实例；
- 达到实例上限：`新建实例` disabled + `实例上限已满`；
- 冷启动：实例卡显示 `启动中`，按钮 disabled；
- 回收中：显示 `回收中`，不允许重复关闭。

### 3.3 操作

- `新建实例`：
  - 为该账号占用一个实例容量；
  - 超过上限 409，提示 `实例上限已满，请先关闭一个实例`；
  - 同账号已有实例时 409，提示 `该账号已有实例`。
- `关闭实例`：
  - 有在途返回 409，提示 `该实例仍有在途请求`；
  - 无在途则进入回收，实例消失，容量释放。
- `切换到此实例`：
  - 只移动当前实例指针；
  - 不影响其他实例；
  - 不合并 cookie；
  - 冷启动/失效时 disabled。
- `重新登录`：
  - 账号失效时使用；
  - 不新建重复实例。

### 3.4 移除

- Cookie 组 → 子账号层级
- 渠道矩阵
- 槽位徽章
- 资格/挂载/命中
- 绑定到槽位
- 设为默认活跃
- 渠道开关
- 页面状态

服务渠道为只读；渠道配置在 P3 高级区。

### 3.5 响应式

- 1024：实例卡单列，操作换行；
- 390：账号信息、实例卡、按钮全部纵向；按钮全宽或两列；
- 不使用横向滚动的账号表。

- 槽位表
- `slots`
- 计划实例

- 任何“实例=页面”的文案

内部页面预算仍存在，由后端默认值管理，不出现在 UI。
