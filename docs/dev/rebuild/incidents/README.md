# Incidents

事故记录唯一入口。一个事故一个文件，使用 `INC-YYYYMMDD-nn-<slug>.md`，不拆成 Gate 系列，不塞进 534 台账。

## 必填字段

- `INC` 编号、日期、上报人
- 影响渠道/上游/账号范围
- 首次发现方式与时间
- 旧/新上游 SHA 或错误指纹
- 是否阻断 B/C、是否暂停迁移
- 已冻结的步骤与在途工作
- 用户裁决与时间
- 限定重审范围
- 恢复原顺序条件
- 证据路径（日志/fixture/请求 ID，脱敏）

## 处置顺序

`检测 → 冻结 → 记录 → 用户裁决 → 限定重审 → 恢复原顺序`

- 主 agent 可以提出暂停或改序请求，不能自行决定。
- 渠道不可逆失效优先于常规迁移；Build/pg/chat 事故不得因“P4/P5 还没到”而搁置。
- 事故期间不得新增 Gate、不得扩大 534、不得静默改 D-xx。
