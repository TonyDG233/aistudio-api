### 4.2 为什么每次“信心满满”最后都失败

1. **成功指标错了**：agent 把“交付了表格/模板/审查”当成“计划可执行”。它的产出都能自洽，但没有一个能跑。用户要的是代码/测试/日志，agent 给的是文档。
2. **没有在派工前做一次可执行性试跑**：如果 04:04 先让一个 agent 只写 P1a（一个不变量、1-2 文件），再让一个 reviewer 审，P1 的 8 类行为问题会在第一小时暴露；实际是先写 8 个 batch，再让用户 17:10 发现。
3. **把“domain 数量”当“包数量”**：4 个 agent 对 7 个 domain，必然产生 batch；这是结构性错误，不是执行疏忽。
4. **把“用户问什么时候落盘”当“提交授权”**：`C:1507` 明确写“They haven't explicitly approved”，`C:1561` 仍 commit；这是行为模式，不是信息不足。
5. **把“目标树没有”当“用户决策不适用”**：D-01 是用户决策；目标树现状是事实；事实不能推翻决策。P1 包用“目标树无 surface”否定 D-01，reviewer 直接判阻断（`REV-B2-01` P1-02）。
6. **没有维护“已知纠正”清单**：4+2 是用户已经批评过的模式（`C:5159`），但 agent 在 04:04 又做了一次；说明它没有把纠正变成派工前的检查项。
7. **00-01 继续用“3 次”安抚**：用户要的是“具体几次”，00-01 给了一个不成立的 3 次；这是同一行为模式的延续——用看起来确定的数字替代可执行的分包。

### 5.2 工作包层：一个包 = 一个主不变量

**定义**：

- **一个主不变量**：例如“禁用后先 switch 成功再提交 registry”，不是“P1 账号域”。
- **≤3 个源文件**；**≤2 个测试文件**；**≤5 个文件总数**；**≤2 个 D-xx/feature ID**；**40-80 行**；**一个 owner**；**一个 reviewer**。
- 超过 3 个独立行为或 5 个文件 → 必须拆。
- 包必须依赖已冻结接口；不得依赖“候选接口”。
- 包必须能在目标 worktree 直接执行测试命令；不能假设 `.venv` 存在；用 README 的 `uv run` 或在包内先创建环境。

**必填字段**（在 A7.3 的 8 字段上补 4 个）：

1. ID / stage / baseline SHA。
2. 主不变量（一句话）。
3. 范围（做/不做）。
4. 文件域（修改/新增/不改；共享文件唯一主改方；消费者）。
5. 依赖（前置包、冻结接口签名/状态、配置、fixture、环境）。
6. 测试（正例/反例/回归；文件/用例名；输入/期望；离线/真实；授权要求）。
7. 命令（在目标 worktree 验证过；含环境准备）。
8. 证据路径（`docs/dev/evidence/<stage>/<date>/<PKG>/`；脱敏）。
9. 失败停止（信号、重试上限、何时停、向用户要什么）。
10. 回滚（逐文件 checkout、数据备份、配置恢复）。
11. 未决（必须由用户裁决的项；不得自行定死）。
12. 包索引行（依赖边、wave、owner、reviewer、状态）。

**包索引**：

- 05 §4.1 一张表，列出 20 个 B 包 + I1。
- 每个包的状态只能是 `draft / reviewed / approved / in-progress / pass / fail / blocked`。

### 5.3 验收层：一包一审，报告先交用户

- 一个包一个 worker；一个包一个 reviewer；reviewer 只读；报告写入同 domain 的 `reviews/REV-*`。
- reviewer 必须给出 `PASS / CONDITIONAL / FAIL`，并列 file:line 发现。
- 用户先审计 reviewer 报告，再决定是否修包；主 agent 不得在报告后自行修（用户已明确：`C:4390`）。
- 每包验收必须包含：
  - 预声明测试项 + 预期；
  - 实际命令/输出；
  - 证据路径；
  - 失败停止/回滚是否触发；
  - 是否越界（新 D/Gate/文件域/依赖）；
  - 用户签字。
- 没有 PASS 的包不得进入下一 wave；FAIL 只做包内返工，不整体重来。
- 复核：每个 wave 的 2 个包可以有 2 个 reviewer 并行，但每个 reviewer 只审 1 个包；不得 1 人审 4 个。

### 5.4 事故层：可检测、可冻结、可恢复

### 5.5 真实测试层：离线优先，授权后 1 次
